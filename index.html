什麼是 CRISP-DM？

CRISP-DM (Cross-Industry Standard Process for Data Mining) 是全球資料科學與商業分析最權威、最普及的標準流程。本作業將 50 Startups 多元線性迴歸問題嚴格對應至 6 大經典階段：

階段 1

Business Understanding (商業理解)

完成

商業痛點： 創投基金 (Venture Capital) 與新創天使投資人每年收到數百家初創公司的融資提案，需要評估「錢投在哪裡回報率最高？」

專案目標： 建立以 R&D Spend、Administration、Marketing Spend 與 State 為特徵的多元迴歸模型，預測年利潤 (Profit)，為投資決策與預算配置提供量化依據。

階段 2

Data Acquisition & Understanding (資料擷取與理解)

完成

資料擷取機制： 使用 Python requests.get() 從指定 GitHub 網址下載 50_Startups.csv，嚴格檢查 response.status_code == 200 確保通訊無誤，再由 io.StringIO 解析為 Pandas DataFrame。

response = requests.get(url); if response.status_code == 200: data = pd.read_csv(io.StringIO(response.text))

資料結構探索： 共有 50 筆觀察值、5 個欄位（4 個數值型、1 個類別型），且缺失值數量為 0（無需填補缺漏值）。

階段 3 關鍵

Data Preparation (資料準備 - 避開虛擬變數陷阱)

完成

1. 特徵與目標切分： 將 Profit 設為目標向量 y，其餘 4 欄設為特徵矩陣 X。

2. 類別資料編碼 (OneHotEncoder)： State 欄位包含 California、Florida、New York 三個字串，需轉為數值 dummy variables。

⚠️
何謂虛擬變數陷阱 (Dummy Variable Trap)？

若 State 有 3 個類別，若同時編碼為 3 個欄位，則 D1 + D2 + D3 = 1，會與線性迴歸公式裡的常數截距項產生完全多重共線性 (Perfect Multicollinearity)，導致特徵矩陣 $X^T X$ 不可逆無法計算。因此必須使用 OneHotEncoder(drop='first') 丟棄第一個基準欄位！

3. 訓練/測試集切分： 使用 train_test_split(..., test_size=0.2, random_state=42) 切割出 40 筆訓練集與 10 筆測試集。

階段 4

Modeling (模型建置 - Multiple Linear Regression)

完成

使用 sklearn.linear_model.LinearRegression 在訓練集 $(X_{train}, y_{train})$ 進行最小平方法 (OLS) 擬合求解。

擬合出的迴歸方程式 (Regression Equation)： Profit = 54028.04 + 938.79 × State_Florida + 6.99 × State_NewYork + 0.8056 × R&D - 0.0688 × Admin + 0.0299 × Marketing
階段 5

Evaluation (模型評估 - 4 大指標與殘差分析)

完成

在未曾參與訓練的 10 筆測試集上進行預測，檢驗泛化能力：

常見考試/口試問答 (Interview & Exam Prep)：

Q: 為什麼必須使用 drop='first'？不加會怎樣？

A: 若不 drop 第一個欄位，三個州別虛擬變數加總恆等於 1，與常數項 (Intercept) 產生多重共線性 (Multicollinearity)。雖然現代 Python 求解器 (SVD) 不會直接報錯崩潰，但係數估計值將失去統計意義，無法正確解釋各州別的真實效應。

Q: 為什麼行政支出 (Administration) 的係數是負數 (-0.0688)？

A: 這說明行政管理等官僚行政開銷在控制了研發與行銷投入後，對利潤並無正面提升作用，甚至代表公司體系冗員較多、運作效率較低。
